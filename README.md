# LLM Interpretability

Code, data, and papers from an ongoing programme on how transformer language
models represent and compute in token space.

**Author:** Olli Tuomi, Evident Solutions Oy
([ORCID 0009-0006-2042-1576](https://orcid.org/0009-0006-2042-1576))

Each paper lives in its own folder with a self-contained README, its scripts,
and the JSON artifacts behind every number in the text.
